🌟 Personal Portfolio Website
Welcome to the repository of my personal portfolio website! Designed and built using core web technologies, this project showcases my skills, experience, and creative work through a clean, modern, and responsive user interface.
🚀 Key Features
🎨 Fully Responsive Design: Seamlessly adapts to all device screens, including mobile, tablet, and desktop.
🌓 Dark & Light Mode: Toggle easily between dark and light visual themes for optimal viewing comfort.
🌐 Bilingual Support (Arabic & English): Switch instantly between English and Arabic language modes to reach a broader audience.
🧭 Dynamic Navigation Bar: Smooth-scrolling sticky navbar enabling easy navigation across all sections (About, Skills, Projects, Contact).
✉️ Working Contact Form: Integrated messaging system that forwards messages directly to my email address.
🔗 Social Media Integration: Direct access links to my professional profiles and social channels.
🛠️ Tech Stack
Built using foundational web standards to ensure high performance, lightning-fast loading, and zero bloat from external frameworks:
HTML5: Semantic structuring and content organization.
CSS3: Custom styling, layout design (Flexbox & Grid), and theme animations.
JavaScript (ES6+): Interactive logic for language translation, theme toggling, and form validation.
📂 Project Structure
portfolio/
│
├── index.html       # Main HTML markup
├── style.css        # Global stylesheet including theme variables
├── script.js        # JavaScript logic (translation, dark mode, form)
└── assets/          # Images, icons, and media files
